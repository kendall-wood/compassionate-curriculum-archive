# Hosting & Costs — plain-language guide

_For Emma (and anyone responsible for keeping the site online and paying for it)._

This explains **where the website lives, what it costs, who pays, and how to manage those payments**. No technical background needed.

---

## 1. The short version

| Thing | What it is | Typical cost |
|---|---|---|
| **Vercel** | The company that runs the website on the internet | **£0** on the free plan; **~£16–20/month** only if you upgrade to Pro |
| **GitHub** | Where the website's code + content is stored | **£0** (free) |
| **Domain name** | A custom web address like `compassionatecurriculum.org` | **~£10–15/year** (optional) |
| **Anthropic API** | Used only when re-generating the 30 translations | **~£0.40 per full re-translation** (pay only when you update content) |

If you change nothing, the only thing that could ever cost money month-to-month is **Vercel**, and only if the project needs the Pro plan. Everything else is either free or a one-off/occasional cost.

## 2. Where the site lives

- The website is built and served by **Vercel** (https://vercel.com).
- Vercel is connected to a **GitHub** repository: `kendall-wood/compassionate-curriculum-archive`.
- **How updates go live:** when a change is saved to GitHub, Vercel automatically rebuilds the site and publishes it within ~1–2 minutes. There is no separate "upload" step and no server to manually maintain.

Think of it as: **GitHub = the filing cabinet, Vercel = the printing press that publishes whatever is in the cabinet.**

---

## 3. What it costs, in detail

### Vercel
- The site is a **static site** (pages are pre-built). This is the cheapest, most reliable kind of hosting.
- **Free ("Hobby") plan:** £0/month. Generous limits — fine for an educational archive with normal traffic. Vercel's terms reserve the Hobby plan for **non-commercial** projects.
- **Pro plan:** ~£16–20/month per member. You'd only need this if (a) the project is considered commercial, (b) traffic grows very large, or (c) you want team members with their own logins.
- **Recommendation:** start on **Hobby (free)**. Upgrade only if Vercel flags commercial use or you outgrow the limits.

### Domain name (optional but recommended)
- Out of the box the site has a free `*.vercel.app` address.
- A custom address (e.g. `compassionatecurriculum.org`) costs **~£10–15/year** from a registrar (Namecheap, Cloudflare, Google Domains, etc.). You point it at Vercel once and it just works.
- This is the only **recurring yearly** cost worth planning for.

### Translations (Anthropic API)
- The site is available in ~30 languages. Those translations are generated by a script that uses **Anthropic's API** (the company behind Claude).
- This costs money **only when you run it** — roughly **£0.40 for a full re-translation of the entire curriculum**. Translating a single changed page costs a fraction of a penny.
- You do **not** need this to keep the site online. It's only used when curriculum **content changes** and you want the other languages updated.
- It requires an **API key** (a password-like string) from https://console.anthropic.com. Whoever runs translations puts a little credit on that account (e.g. £5 lasts a very long time).

## 4. Who owns and pays for what

This is the part to **decide and write down**, so there's no confusion later:

1. **Vercel account** — Who is the account owner? (Recommended: an account in the project's/organisation's name, not a personal student account that might disappear.) The owner's card is what gets charged *if* the project ever moves to Pro.
2. **GitHub account** — Currently under `kendall-wood`. Decide whether the repo should move to an organisation account so it isn't tied to one person.
3. **Domain** — Who registers and renews it each year? Set the renewal to **auto-renew** and put the login somewhere shared so it can't lapse.
4. **Anthropic API** — Who holds the key and tops up the small credit when content is re-translated?

> **Suggested setup for stability:** create a single shared "project" email (e.g. a Gmail), and register Vercel + GitHub + the domain + Anthropic under that email. Then ownership isn't tied to any one individual, and logins/payment can be handed over cleanly.

## 5. How to manage payments (step by step)

- **Vercel:** Log in → _Settings → Billing_. On Hobby there's nothing to pay. If you ever upgrade, you add a card here and can see invoices.
- **Domain:** Log in to the registrar → enable **auto-renew** → keep a card on file. Expect one ~£10–15 charge per year.
- **Anthropic:** Log in to console.anthropic.com → _Billing_ → add a small prepaid credit. You're only charged as the translation script uses it.

There are **no monthly server bills, no databases to pay for, and no per-user fees** in the current setup.

---

## 6. What you do *not* have to worry about

- No physical or virtual server to patch or restart.
- No database hosting fees.
- No CDN/bandwidth bill under normal traffic (included free).
- The site keeps running even if no one touches it for months.

---

## 7. If something goes wrong (who to contact)

- **Site is down / shows an error:** check the Vercel dashboard → _Deployments_. The most recent deployment will show "Ready" (good) or "Error" (a build failed — the previous working version stays live).
- **A change didn't appear:** confirm it was saved to GitHub; Vercel deploys automatically after that.
- For anything code-related, the developer can roll back to any previous version in one click from the Vercel dashboard.
